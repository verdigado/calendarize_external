============
Installation
============

*  just install from TER through Extension manager or by composer using

   .. code-block:: bash

      composer req verdigado/calendarize_external

*   The essential dependency is :ref:`lochmueller/calendarize <ext_calendarize:Installation>`

    To get the patch mentioned in the introduction for TYPO3 v10 or v11 you can use:

   .. code-block:: bash

      composer req lochmueller/calendarize dev-v11@dev
